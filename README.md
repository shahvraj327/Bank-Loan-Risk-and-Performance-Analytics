# 🏦 Bank Loan Analysis Dashboard

A comprehensive **Bank Loan Analysis Dashboard** built using **Power BI** and **SQL** to analyze loan applications, funding, repayments, customer demographics, and loan performance. This project provides valuable business insights through interactive dashboards and data-driven visualizations.

---

##  Project Overview

The objective of this project is to analyze bank loan data to help financial institutions monitor loan performance, identify trends, and make informed lending decisions.

The dashboard provides insights into:

- Loan Applications
- Funded Amount
- Amount Received
- Loan Status
- Interest Rates
- Debt-to-Income (DTI) Ratio
- Customer Demographics
- Monthly Loan Trends
- Regional Loan Distribution
- Loan Purpose Analysis

---

##  Features

-  Interactive Power BI Dashboard
-  Loan Performance Analysis

-  Funded vs Received Amount Comparison
